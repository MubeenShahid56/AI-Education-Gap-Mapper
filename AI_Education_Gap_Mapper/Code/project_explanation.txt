Project Explanation - AI Education Gap Mapper

Files and what they do:
- app.py
  - Flask web application that serves the dashboard and REST API endpoints.
  - Loads saved model artifacts (`models/best_model.pkl`, `models/vectorizer.pkl`), evaluation metrics, and the domain skills database on startup.
  - Provides endpoints: `/` (UI), `/api/courses` (preloaded courses), `/api/metrics` (model metrics), and `/api/analyze` (accepts course data, extracts skills, predicts domain, returns gap analysis and recommendations).
  - Implements text-based skill extraction, domain matching, and gap-calculation utilities used by the frontend.

- model.py
  - Training pipeline: reads `ai_job_skills.csv`, categorizes job titles into domains, cleans skill lists, vectorizes skills using TF-IDF, trains three classifiers (MultinomialNB, DecisionTree, RandomForest), evaluates them, saves the best model and vectorizer, and builds a domain-skills JSON database.
  - Outputs: `models/best_model.pkl`, `models/vectorizer.pkl`, `models/metrics.json`, `models/domain_skills.json`.

- run.py
  - Lightweight launcher ensuring the Flask app runs inside the project `.venv` if present. Imports `app` and calls `app.app.run(...)` to start the server.

- courses.json
  - Preloaded course catalog used by the UI and for comparison when determining domain alignment.

- ai_job_skills.csv / job_skills.csv
  - Data sources: scraped/filtered job-skill lists used to train models and derive top skills per domain.

- templates/ and static/
  - Frontend assets: `templates/index.html` is the dashboard UI; `static/` contains CSS and JS used by the client to call the API and render visualizations.

- models/ (generated by `model.py`)
  - `best_model.pkl`: serialized chosen classifier.
  - `vectorizer.pkl`: TF-IDF vectorizer used for feature transformation.
  - `metrics.json`: evaluation metrics for each candidate model.
  - `domain_skills.json`: top skills per domain (counts and percentages) used for gap analysis and recommendations.

Key libraries and what they do (short):
- Flask / flask_cors: Host the web dashboard and expose REST API endpoints.
- pandas / numpy: Load and manipulate tabular datasets (CSV processing, counting, grouping).
- scikit-learn (sklearn)
  - `TfidfVectorizer`: converts skill lists / text into numeric feature vectors with TF‑IDF weighting.
  - `train_test_split`: create training and test partitions (stratified to preserve domain balance).
  - `MultinomialNB`, `DecisionTreeClassifier`, `RandomForestClassifier`: classifiers used to map skills to job domains.
  - metrics (accuracy, precision_recall_fscore_support, classification_report): evaluate model performance.
- pickle / json / os / re: save/load artifacts, read/write JSON, file path handling, and regex-based text matching.

Why these three models were included (brief):
- Multinomial Naive Bayes (MultinomialNB): Fast, low-compute baseline suited for discrete count-style text features (bag-of-skills). Good starting point and often strong on high-dimension sparse text data.
- Decision Tree: Provides interpretability — you can inspect decision paths and understand which features (skills) drive splits. Useful diagnostic and contrast model.
- Random Forest: An ensemble of decision trees that reduces variance and overfitting compared to a single tree; usually yields robust, higher accuracy on varied data. It is a strong candidate to be the final saved model.

Why TF‑IDF and processing choices (short):
- Skills are treated as text tokens; TF‑IDF captures term importance across documents (job listings) and down-weights very common tokens.
- `sublinear_tf=True` resists extreme frequency domination, `max_features=5000` limits vocabulary to the most informative terms for efficiency.

Outputs and usage:
- After running `model.train_and_evaluate()`, the `models/` folder contains artifacts used by `app.py` to predict domains and compute gap analysis in real time.
- The Flask API uses the saved `vectorizer` + `model` to classify course skills and then compares them to top industry skills to produce alignment scores and recommendations.
