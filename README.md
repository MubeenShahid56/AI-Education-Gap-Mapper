AI Education Gap Mapper is a machine learning-based system designed to identify skill gaps between university AI education and industry requirements. The project analyzes AI-related job descriptions and compares the required industry skills with academic course content to highlight missing or underrepresented skills. Using NLP techniques such as TF-IDF vectorization and machine learning models, the system categorizes job roles, extracts important skills, and provides insights into areas where AI education can be improved to better align with industry demands.

Key Features:

Analyzes AI job market skills using real-world job data.
Applies Natural Language Processing (NLP) for skill extraction and classification.
Uses machine learning models to identify job domains and required skills.
Compares academic AI curriculum with industry skill requirements.
Generates data-driven insights to improve AI education alignment.

Technologies Used:

Python
Machine Learning (Naive Bayes, Decision Tree, Random Forest)
NLP (TF-IDF)
Pandas, Scikit-learn
Data Visualization
Jupyter Notebook
